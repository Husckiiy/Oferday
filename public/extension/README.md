# Oferday Cookie Sync - Extensão do Navegador

Sincroniza automaticamente os cookies de sessão de afiliados do **Mercado Livre** (`meli.la`) e **Amazon SiteStripe** (`amzn.to`) diretamente com o bot Oferday!

## Como Instalar (Chrome, Edge, Brave, Opera):
1. Acesse `chrome://extensions` (ou `edge://extensions`)
2. Ative a opção **"Modo do desenvolvedor"** no topo direito.
3. Clique no botão **"Carregar sem compactação"** (Load unpacked).
4. Selecione a pasta `extension` deste projeto.
5. Pronto! Agora basta abrir a extensão e clicar em **"🔄 Sincronizar em 1 Clique com o Bot"**.
